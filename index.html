Does it work on macOS 26 Tahoe?

Yes, fully updated for macOS 26 Tahoe and earlier versions.

Do I need multiple devices?

Yes, run on two Macs: one as server, one as client.

How accurate are the results?

Highly accurate using direct client-server transfers, reflecting true network performance.

Is setup complicated?

No—automatic Bonjour discovery handles everything in seconds.
